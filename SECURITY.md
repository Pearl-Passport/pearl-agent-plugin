# Security

Report suspected vulnerabilities privately to `hello@joinpearl.co` with `[Security]` in the subject line. Do not open a public issue containing credentials, member data, authorization codes, tokens, or exploit details.

This repository must never contain an OAuth client secret, access token, refresh token, bearer token, personal token, private key, application environment file, or production deployment configuration. The identifiers `pearl-claude-hosted` and `pearl-cursor` are public OAuth client IDs, not credentials.

For account help or non-security problems, use https://joinpearl.co/support.
